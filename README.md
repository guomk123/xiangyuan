产品需求与 UI 规范文档 (PRD)
品牌主色调: #7658FE | 设计风格: 优雅沉浸式iOS拟态

1. 核心定位与用户体验 (UX) 创新路径
摆脱了传统健身App单一的“打卡记录”模式，引入了“神经适配闭环 (Neural-Adaptability Loop)”。系统每日读取用户的 HRV（心率变异性）、睡眠质量与肌肉恢复热力图，在首页实时生成 身心恢复准备度得分，自动下发当日最优训练容量。
2. 四大核心 TAB 页面功能拆解
Tab 1: 训练 (Train & Plan)
AI 恢复度评估、动态计划生成器、肌肉疲劳热力图、沉浸式组间休息计时执行器。
Tab 2: 数据 (Data & Health)
容量趋势 Chart.js 堆叠图、4维核心KPI、体成分肌肉量追踪与HealthKit同步。
Tab 3: 饮食 (Diet & Nutrition)
三大营养素动态环形进度条、AI 拍照识别图像估算热量、训练前/后补充建议。
Tab 4: 设置 (Settings)
AI 语音教练人设切换、设备连接管理、重量调整敏感度与个人目标配置。
3. UI 设计语言规范 (DESIGN SYSTEM)
主色调 (Brand Accent): #7658FE (充满未来感的紫罗兰色，彰显高能与优雅)。
背景色 (Background): 深邃深紫夜色 #0B0814 与 #161228，彻底避免平庸白色，带来沉浸式视觉。
质感 (Material): 轻盈微光毛玻璃 (Glassmorphism + Backdrop Blur 16px)，搭配细腻圆角 (24px - 32px)。
